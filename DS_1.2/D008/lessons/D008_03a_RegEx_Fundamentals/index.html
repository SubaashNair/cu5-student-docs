D08 · Regular expressions for text data

Unit: DS 1.2 Data Preparation & Statistical Modelling · Day 8 of 21

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Patterns for text. Literal matching, character classes, quantifiers, anchors, capture groups, findall, search and sub, and flags such as case-insensitive. Built up from the string methods of DS 1.1 D02 toward emails, phone numbers and dates.

By the end of this lesson you can
  1. Write a pattern that matches emails, phone numbers or dates in a block of text.
  2. Use character classes and quantifiers to express 'one or more digits' and similar.
  3. Anchor a pattern to the start or end of a line.
  4. Capture groups and pull the pieces out of a match.
  5. Substitute matches to normalise a messy column.
Why this matters

Text columns, log files, scraped pages on D09 and tokenisation on D11 all need this. A regex is the difference between cleaning a column in one line and in an afternoon.
