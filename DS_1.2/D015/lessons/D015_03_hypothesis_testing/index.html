D15 · Hypothesis testing: z, t, errors, effect size and a first ANOVA

Unit: DS 1.2 Data Preparation & Statistical Modelling · Day 15 of 21

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Making a claim with a stated risk. Null and alternative hypotheses and fixing alpha before looking, Type I and Type II error in the court-room framing, the z-test by hand and by library, t-tests for one sample, two samples and paired data, checking normality and equal variance first, effect size as the number p cannot give, and a first one-way ANOVA with a post-hoc test.

By the end of this lesson you can
  1. State H0 and H1 and fix alpha before running anything.
  2. Explain Type I and Type II error and what alpha equal to 0.05 buys and costs.
  3. Run a z-test by hand (standard error, z, p) and check it against a library.
  4. Choose Student or Welch from a variance check and run the right t-test.
  5. Report an effect size and a confidence interval alongside p.
  6. Run a one-way ANOVA and a post-hoc test and read them pair by pair.
Why this matters

'Is B better than A' is the most common question an analyst is asked. The assessment's trap is a tiny effect with a tiny p-value bought with sample size.
