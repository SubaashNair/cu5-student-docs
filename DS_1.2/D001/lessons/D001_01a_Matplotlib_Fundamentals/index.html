What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Why a chart is a check on a number, and the five basic plots. Anscombe's quartet shows four datasets with identical summary statistics and different shapes; then line, scatter, bar, histogram and pie with labels, titles, legends and colours, and saving a figure to a file. A decision guide maps variable types to chart types.

By the end of this lesson you can
  1. Choose a chart type from the variable types and the question being asked.
  2. Make a line, scatter, bar, histogram and pie chart from a DataFrame.
  3. Label axes and title a figure so it can be read without the code.
  4. Save a figure to a file at a stated resolution.
  5. Explain, using Anscombe's quartet, why summary statistics alone can mislead.
Why this matters

Every finding in the credential is communicated as a chart, and every assessment from D03 on requires labelled axes. Anscombe's quartet is the argument the student will use when a stakeholder asks for 'just the average'.
