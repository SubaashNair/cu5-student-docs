D02 · Data cleaning and class imbalance

Unit: DS 1.3 Machine Learning and Deep Learning · Day 2 of 25

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

When one class is rare. Reporting the balance, why accuracy fails on a 1 percent positive class, the confusion matrix read for that case, random over- and under-sampling and SMOTE applied to the training set only, and class_weight as the alternative that counts real rows more instead of inventing new ones.

By the end of this lesson you can
  1. Report the class balance and state the accuracy a majority classifier achieves.
  2. Apply SMOTE and random resampling to the training rows only and say what each changes.
  3. Use class_weight='balanced' and compare its effect with resampling on recall and precision.
  4. Read a confusion matrix for a rare positive class and name the costly cell.
Why this matters

Fraud, escalation, churn and defects are all rare positives. The D02 paper's model scores 99 percent accuracy and catches 11 of 75 emergencies.
