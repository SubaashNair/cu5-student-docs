D20 · Embeddings and multi-input models

Unit: DS 1.3 Machine Learning and Deep Learning · Day 20 of 25

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Mixed inputs in one model. Three inputs (two team embeddings and a home-advantage flag), the architecture as a graph, concatenation, training and comparison with the two-input model.

By the end of this lesson you can
  1. Build a model with categorical and numeric inputs using the functional API.
  2. Concatenate branches and add a head.
  3. Compare models with and without an extra input on held-out data.
Why this matters

Real records mix IDs, numbers and flags. The heart-disease case study on this day asks for a multi-input model of its own.
