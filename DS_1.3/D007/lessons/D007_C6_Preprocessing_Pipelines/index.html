Unit: DS 1.3 Machine Learning and Deep Learning · Day 7 of 25

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

The workflow as one object. Pipeline, ColumnTransformer for mixed columns, cross-validation and grid search run on the pipeline so nothing leaks, named_steps to reach a fitted step, a custom transformer, and saving the whole thing with joblib. The wrong-way and right-way contrast makes leakage concrete.

By the end of this lesson you can
  1. Build a Pipeline of transformers ending in an estimator.
  2. Route numeric and categorical columns separately with ColumnTransformer.
  3. Cross-validate and grid-search a pipeline and explain why nothing leaks.
  4. Reach a fitted step's parameters and save and reload the pipeline.
Why this matters

This is the object that goes to production. Every later day's model should live inside one; the D07 paper's hand-over note is written for the engineer who runs it.
