D05 · Functions

Unit: DS 1.1 Python Fundamentals · Day 5 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Reusable code with a name. Defining a function with parameters, calling it, returning a value versus printing one, default arguments, a docstring, and the DRY principle as the reason to write one. Variables created inside a function are shown to be local.

By the end of this lesson you can
  1. Define a function with parameters and a return value and call it with different inputs.
  2. Distinguish a function that returns from one that prints, and say which a caller can reuse.
  3. Give a parameter a default and call the function with and without it.
  4. Refactor two repeated blocks into one function without changing the output.
Why this matters

apply() on D13 takes a function; every reusable analysis step in DS 1.2 and DS 1.3 is one. Assessments from here on mark a task down when a value is printed instead of returned, because a printed value cannot be tested.
