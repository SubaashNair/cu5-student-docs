D09 · NumPy arrays, aggregation and masking

Unit: DS 1.1 Python Fundamentals · Day 9 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

The array. Creating arrays from lists and with generators (zeros, ones, arange, linspace), shape and dtype, arithmetic on whole arrays without a loop, aggregation (sum, mean, min, max, std) along an axis, indexing and slicing in one and two dimensions, and the boolean mask: a comparison applied to the whole array used to select elements.

By the end of this lesson you can
  1. Create an array of a given shape and dtype and read both back.
  2. Replace a D04 loop with a single vectorised expression and show the results match.
  3. Aggregate a 2-D array along rows and along columns and say which axis is which.
  4. Select elements with a boolean mask built from a comparison.
  5. Explain why an int array cannot hold a decimal and what happens when you try.
Why this matters

pandas sits on NumPy, so every column operation on D11 onward is an array operation. Every statistic in DS 1.2 D13 is an aggregation; every filter is a mask; images and model weights in DS 1.3 are arrays.
