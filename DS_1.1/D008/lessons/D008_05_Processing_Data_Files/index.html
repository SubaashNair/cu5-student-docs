D08 · Reading data files: CSV, Excel, PDF

Unit: DS 1.1 Python Fundamentals · Day 8 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Getting data in and out of a program. Opening files with a with-block, the modes, reading whole files and line by line, writing, parsing a delimited line into fields, the difference between bytes and text, JSON load and dump, and CSV through the csv module. Paths are handled explicitly so a missing file is a readable error.

By the end of this lesson you can
  1. Read and write a text file inside a with-block and explain why the block closes the file.
  2. Parse delimited lines into lists and dictionaries, converting fields to numbers.
  3. Load a JSON file into nested dictionaries and lists, and write one back.
  4. Read a CSV with csv.DictReader and compute a total from one column.
  5. Handle a missing file with a clear message instead of a traceback.
Why this matters

pd.read_csv on D11 does all of this in one call; knowing what is underneath is what explains encoding, delimiter and quoting errors when it fails. Every project in the credential begins by loading a file, and the spine dataset enters here.
