D08 · Reading data files: CSV, Excel, PDF

Unit: DS 1.1 Python Fundamentals · Day 8 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Text that is locked inside a PDF. Installing pypdf, opening a document, extracting text page by page, splitting it into lines, saving the result to a text file, and recognising the common failure: a scanned PDF with no text layer, which needs OCR rather than parsing.

By the end of this lesson you can
  1. Extract the text of every page of a PDF into a single string.
  2. Split extracted text into lines and pull out the lines that match a target.
  3. Save extracted text to a file for later processing.
  4. Recognise from empty output that a PDF is an image and say what would be needed instead.
Why this matters

Reports, invoices, annual accounts and government statistics arrive as PDFs. The extracted text feeds regex cleaning on DS 1.2 D08 and the NLP pipeline on D11.
