What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

What a program is and how Python runs one: the interpreter reads a cell top to bottom, print() is how a value becomes visible, and a comment is text for the human reader that the interpreter skips. The lesson also sets the working habit of the whole course: run a cell, read the output, compare it with what you expected.

By the end of this lesson you can
  1. Run a cell in Jupyter and locate its output and its error text.
  2. Use print() to display a literal, a calculation and several values in one call.
  3. Write a comment that says why a line exists, not what it does.
  4. Describe in one sentence what the interpreter does with a line of code.
Why this matters

Every notebook in the credential is a program, and every assessment is marked on code plus a written justification, so the comment habit starts here. Reading an error message calmly is the single skill that most separates students who finish a code-along from those who stall.
