What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Making new columns. apply with a function from D05 on a column and on a row, np.where for a conditional column, converting text to datetime and extracting year, month and weekday, the .str accessor for text columns, and pivot tables as a two-way groupby.

By the end of this lesson you can
  1. Apply a named function and a lambda to a column and produce a new column.
  2. Create a conditional column with np.where instead of a loop.
  3. Convert a string column to datetime and extract month and day of week.
  4. Build a pivot table and read it back as a groupby with two keys.
Why this matters

This is feature engineering by another name. Month and weekday columns drive most business charts; apply and np.where are how DS 1.2 recodes categories and DS 1.3 builds features.
