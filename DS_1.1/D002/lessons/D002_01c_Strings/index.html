D02 · Strings and formatting

Unit: DS 1.1 Python Fundamentals · Day 2 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Text as a sequence: creating strings with either quote, concatenation and repetition, indexing single characters (including negative positions), slicing ranges with start:stop:step, the common methods (upper, lower, strip, split, replace, find, count), and f-strings for formatted output with width and precision. Strings are immutable, so every method returns a new string.

By the end of this lesson you can
  1. Index and slice a string to extract a character or a substring, including from the end.
  2. Apply string methods to clean and reshape text, and explain why the original is unchanged.
  3. Format a sentence with an f-string, controlling decimal places and column width.
  4. Split a delimited line into parts and join them back with a different separator.
Why this matters

Raw data is text: names, codes, addresses, dates as strings. The methods here become the pandas .str accessor on D13 and the regex work of DS 1.2 D08. Slicing syntax is reused unchanged on lists (D06) and arrays (D09).
