D07 · Dictionaries and sets

Unit: DS 1.1 Python Fundamentals · Day 7 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Lookup by key. Creating and reading dictionaries, adding and changing entries, the methods (keys, values, items, get, update), iterating over pairs, nested dictionaries, and counting with a dictionary. Sets for uniqueness and membership, with union, intersection and difference.

By the end of this lesson you can
  1. Look up, add and update a value by key, and use get() so a missing key does not crash.
  2. Iterate over a dictionary's items and build a second dictionary from the first.
  3. Count occurrences of items with a dictionary.
  4. Deduplicate a list with a set and test membership in constant time.
  5. Choose between a list and a dictionary from how the data will be looked up.
Why this matters

JSON on D08 is dictionaries and lists all the way down. A DataFrame is built from a dictionary of columns on D11, and recoding a column (map a code to a label) is a dictionary lookup. Sets are how you check which IDs are in one table but not another.
