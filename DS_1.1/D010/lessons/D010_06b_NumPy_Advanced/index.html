D10 · NumPy broadcasting, fancy indexing and linear algebra

Unit: DS 1.1 Python Fundamentals · Day 10 of 14

What to do today

Read this brief, then download and run the lesson notebook from Downloads.

Concept taught

Arrays of different shapes working together. The broadcasting rules and how to predict whether two shapes are compatible, fancy indexing with an array of positions, argsort for sorting one array by another, stacking and splitting, and matrix operations (dot product, transpose). Centering data by subtracting a column mean is the worked example.

By the end of this lesson you can
  1. Predict whether two shapes broadcast and what the result shape is.
  2. Standardise every column of a 2-D array in one expression.
  3. Select rows with an index array and reorder an array with argsort.
  4. Stack arrays vertically and horizontally and predict the shape.
  5. Compute a dot product and check it against the loop version.
Why this matters

Standardising features is broadcasting; 'top ten' is argsort; the dot product is how regression on DS 1.2 D19 and every neural-network layer in DS 1.3 computes. A student who can predict a broadcast shape can read a shape-mismatch error.
